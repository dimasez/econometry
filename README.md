# Эконометрия — личный учебный проект

Цель проекта: освоить эконометрию с нуля до уровня, на котором я могу **самостоятельно решать семинарские и экзаменационные задачи, понимать предпосылки моделей, интерпретировать результаты и объяснять решения словами**.

Основной учебник: **Суслов В. И., Ибрагимов Н. М., Талышева Л. П., Цыплаков А. А. — «Эконометрия»**.

> В учебнике курс устроен как четыре крупных блока: социально-экономическая статистика, регрессионный анализ, временные ряды и «Эконометрия II». Сам учебник предполагает базу по линейной алгебре, математическому анализу, теории вероятностей и математической статистике, поэтому эту базу будем восстанавливать по мере необходимости, а не пытаться сначала «выучить всю математику».

## Главный принцип

Каждая тема проходит 5 уровней:

1. **Интуиция** — что мы вообще пытаемся узнать из данных.
2. **Обозначения** — что означает каждая буква в формуле.
3. **Механика** — как считается оценка/статистика руками.
4. **Статистика** — какие предпосылки нужны и что случайно.
5. **Интерпретация** — что можно и нельзя утверждать по результату.

Тема не считается изученной, пока я не могу:

- объяснить идею без формул;
- записать ключевую формулу и расшифровать каждый символ;
- решить минимум 3 типовые задачи без подсказки;
- распознать, какие предпосылки модели используются;
- интерпретировать численный результат нормальным экономическим языком.
