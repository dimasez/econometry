# Workflow: как использовать ChatGPT в этом проекте

## 1. Когда появляется новая лекция / семинар / ДЗ

Я загружаю файл и пишу, например:

> «Разбери этот семинар. Сначала скажи, какие темы из roadmap нужны, потом объясни теорию простыми словами, затем реши задачи по одной, не пропуская алгебру.»

После этого обновляем:

- `PROGRESS.md` — что стало понятно/непонятно;
- `ROADMAP.md` — если преподаватель идёт в другом порядке;
- при необходимости создаём отдельный файл `notes/<topic>.md`.

## 2. Формат разбора любой задачи

Каждую задачу разбираем по одному шаблону:

1. **Что дано.**
2. **Что требуется найти/проверить.**
3. **Какая модель используется.**
4. **Какие предпосылки нужны.**
5. **Какой метод/формула применяются.**
6. **Расчёт без пропуска шагов.**
7. **Экономическая интерпретация ответа.**
8. **Типичная ошибка в такой задаче.**
9. **Мини-задача для самостоятельной проверки.**

## 3. Режим «объясни совсем с нуля»

Для сложной темы использовать запрос:

> «Объясни тему в 4 слоя: бытовая интуиция → маленький численный пример → формальная запись → типовая экзаменационная задача.»

## 4. Режим самопроверки

Запрос:

> «Устрой мне устный зачёт по теме X. По одному вопросу за раз. Не подсказывай сразу. После моего ответа оцени точность и задай следующий вопрос.»

## 5. Режим перед семинаром

Запрос:

> «Мне через час семинар по теме X. Дай минимальный набор, который позволит не потеряться: 5 понятий, 5 формул, 3 типовые задачи и 5 ловушек.»

## 6. Режим после семинара

Запрос:

> «Вот мои записи/фото. Сопоставь их с учебником, восстанови пропущенные шаги и сформируй список того, что я должен уметь к следующему занятию.»

## 7. Режим перед контрольной

Запрос:

> «По моему PROGRESS.md составь пробную контрольную только по темам, которые реально были в загруженных материалах. После решения сделай разбор ошибок и обнови список слабых мест.»

## 8. Правило источников

Если загружены материалы преподавателя, приоритет такой:

1. формулировки и обозначения преподавателя;
2. задания и семинарские листки;
3. основной учебник;
4. внешние пояснения — только как дополнительная интуиция.

Это снижает риск выучить «правильную эконометрику», но не ту нотацию или не тот метод решения, который ожидают на курсе.
